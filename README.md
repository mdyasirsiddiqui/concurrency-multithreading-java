# Java Concurrency & Multithreading Practice

A growing collection of interview questions, code examples, and conceptual notes covering all major topics in Java concurrency and multithreading. This repository is designed to strengthen understanding of threading, synchronization, and concurrent programming patterns.

📌 Topics

✅ Implemented Topics
- Thread lifecycle (new, runnable, running, waiting, terminated)
- Runnable vs Callable
- Executor framework (ExecutorService, ThreadPoolExecutor)
- Producer–Consumer pattern (wait/notify)
- Exception handling in threads

📝 Planned Topics
- Synchronization (synchronized, Lock, ReentrantLock)
- Concurrency utilities (Semaphore, CountDownLatch, CyclicBarrier)
- Thread-safe collections (ConcurrentHashMap, CopyOnWriteArrayList)
- Atomic classes (AtomicInteger, AtomicReference)
- Future and CompletableFuture
- Fork/Join framework
- BlockingQueue-based Producer–Consumer
- Concurrency issues: Race conditions, Deadlocks, Livelocks, Thread starvation
- Best practices for thread safety
